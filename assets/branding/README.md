# Icono Allowance Privacy

Fuente original del fork: icon.svg. Paleta #101A2A, #273C56 y #96DCC1. Sin texto.
Regenerar desde la raíz: `python3 tools/generate_icons.py` (Python 3 e ImageMagick `convert`).
El script genera PNG de launcher en cinco densidades y vectores foreground/monochrome. XML adaptativo v26 y v33 referencia esos vectores y el fondo en colors.xml.
La capa monocroma es una silueta opaca para el tema del launcher. Previsualización: icon-preview.png. No se ha inspeccionado en launcher Android.
Recursos creados para este fork y distribuidos con GPL-3.0 del proyecto.
